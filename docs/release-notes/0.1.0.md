### Added

- Search for file names and paths within ZIP archives across local disks and mounted SMB or NFS shares.
- Update the local search index automatically and keep cached results visible when a source is offline.
- Reveal ZIP archives in Dolphin, open individual files from a temporary copy, and extract selected files.
- Install on x86_64 Linux using a Flatpak bundle with the GNOME 50 runtime. The app targets Fedora 44 with KDE Plasma and Wayland.
